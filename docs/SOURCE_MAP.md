# Source map

This public tree contains the model, data, training, inference, and validation
components required for a maintainable VidDub release. Cluster launchers,
machine-specific configuration, logs, experimental media, benchmark downloads,
cached bytecode, failed checkpoints, and research-only reports are excluded.

The repository retains a reduced `viddub/foundation/` fork containing only the
Wan2.1-VACE foundation used by VidDub. It is based on upstream commit
`7686e54d41d25c0e8ed5f1318acc23b6bb832654`; unrelated model families and Wan
extensions are excluded.
